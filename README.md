### 👋 About me

I'm a **SOC Analyst**. I build hands-on SOC labs and write up everything I study, so it can be read again before an investigation or an interview.

Everything lives on **[Blue Team Notes](https://ammaryasser28.github.io/)**: one place to search all the notes, follow each course as a map of its topics, read the diagrams, and keep track of what you have finished. The notes are written in Arabic (Egyptian dialect), with every technical term and command kept in English.

### ⭐ Start here

- [**Interpreting Important Events**](https://ammaryasser28.github.io/?t=sec450&n=450.3%20-%20Understanding%20Hosts%2C%20Logs%2C%20and%20Files%2FInterpreting%20Important%20Events.md): the Windows and Linux events an analyst reads every shift: 4624, 4625, 4688, 7045 and Kerberos.
- [**MITRE ATT&CK Framework**](https://ammaryasser28.github.io/?t=essentials&n=Security%20Framework%2FMITRE%20ATT%26CK%20Framework.md): tactics, techniques and procedures, and how the matrix describes a real intrusion.
- [**Pyramid of Pain**](https://ammaryasser28.github.io/?t=essentials&n=Pyramid%20of%20Pain.md): why blocking a hash barely slows an attacker down, and blocking their behaviour does.
- [**Cyber Kill Chain**](https://ammaryasser28.github.io/?t=essentials&n=Security%20Framework%2FCyber%20Kill%20Chain.md): the seven phases of an attack and where a SOC can break the chain.
